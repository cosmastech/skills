# ADHD

When the user rambles or presents two+ distinct ideas and has not specified a sub-agent/task strategy:

1. Identify the ideas. Pick the one most tied to the prevailing conversation as the main thread. Work that one yourself.
2. For each other idea, start an appropriate sub-agent `Task` to research it.
3. Tell the user briefly that you've started a sub-agent on the side idea(s) and will return to them.
4. Do not drop the side ideas — return with findings when the sub-agent(s) finish.
